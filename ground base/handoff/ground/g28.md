## Behavior

Every latching stimulus calls `SafetyPort.request` once, before any vision, RSSI, or model wait. The Task 01 safety double returns a new handle on every call, so a second halt does not call it again. The stored handle is returned. Dog halt is the copied `dog.command` with action `halt`. The drone command is `hover` or `land` from the copied examples. `emergency`, `motor_cut`, `power_off`, and `cut_motors` are rejected and never emitted. An armed profile of `land` selects the land example. Link loss uses `link_loss_action` when that field is present, otherwise the armed profile. Explicit land uses the land example even when the armed profile is hover.

Accepted message kinds:

- `dog.command` / `halt` — `ground-to-dog-halt.json`
- `drone.command` / `hover` — `ground-to-drone-hover.json`
- `drone.command` / `land` — `ground-to-drone-land.json`

Lease expiry refuses the unstarted command, sets execution to `unknown`, and names a query path without importing it: dog commands ask `feature.v2_dog_ack` (task 24); drone commands ask `feature.v2_drone_ack` (task 18). Link loss sets delivery to `unknown`, `physical_stop_claimed` false, `local_failsafe` true, and `delivery_guaranteed` false. Obstacle block, noisy RSSI, lost track, and a stale frame halt or stop homing and do not count as arrival or `goal_reached`. A `person_visible` decision does not clear the latch. Search, track, and homing proposals are refused while the latch is set, and they are not granted before it is set.

Reset requires the fixture token and no pending workers. A missing token, a wrong token, a boolean, the string `"false"`, a `workers_pending` true flag, or a retained task all leave the latch set. A matching token with no pending work calls `SafetyPort.reset` and clears the latch. It does not authorize a route.

The journal record stores the stimulus, latch monotonic time, superseded command ids, and the correlation ids present on the emitted command (`message_id`, `mission_id`, `epoch`, `command_id`, `track_id`, `beacon_epoch`). Null measurements are omitted rather than written as zero.

## Extra edge cases

- A blank stimulus does not latch.
- `workers_pending: "false"` and `recovery_token: true` are rejected. They are not coerced.
- A wrong token is rejected and `safety.reset` is not called.
- A retained task blocks reset even when `workers_pending` is false. After that task finishes, the same token clears the latch.
- Link loss with `link_loss_action: hover` stays on hover when the armed profile is land.
- An `emergency` profile is recorded as rejected and the drone command stays hover.
- An ordinary proposal before the latch does not emit a dog command.
- A stale `person_visible` decision in the same request as the latch does not clear it, and no model call is counted.
- The second halt journals `duplicate: true` with the original latch time and the same superseded ids `cmd-dog-001`, `cmd-drone-001`.

## Limitations

- `python -m patrol.ground.sim --task 28` cannot load the manifest until Gate C admits `ground-task-v2` and `feature.v2_safety`. The harness run above is the simulation evidence.
- This machine has CPython 3.12.10 only. Mypy checks with `python_version = 3.11`.
- Commands are copied contract envelopes. The v1 device doubles are not asked to `halt` or `land`, so no physical stop is claimed. Link-loss delivery stays unknown.
- The safety double does not coalesce handles. Idempotence is enforced here by storing the first handle.
- Nothing here measures Go2 stop time, Tello hover or landing, or whether a command arrived after the link dropped. Onboard failsafes stay with the dog and drone teammates.
- Reset does not replay a route. It also does not by itself arm the next mission.
