## Behavior

`accept` journals one envelope. It copies `message_id`, `mission_id`, `epoch`, `source`, `destination`, `kind`, and `sent_at` onto every record, and copies `command_id`, `request_id`, `proposal_id`, `frame_id`, `track_id`, `beacon_epoch`, `map_epoch`, and `camera_epoch` when present. A command or acknowledgement without `command_id` is rejected. A vision request or decision without `request_id` or `frame_id` is rejected. Nothing is emitted for a rejection.

`demo_goal_reached` stays a completion event. `landing_unverified` stays a safety event. They are not the same name. A landing acknowledgement stays an acknowledgement named `landing_not_verified`.

Enqueue sets `writer_state` `queued` and `published` false. `flush` moves queued records to `flushed` and still does not publish. `publish` runs only after every record is flushed. A failed flush sets `writer_state` `failed`, emits `persistence_fault`, and does not call publish. The same `message_id` does not append a second record.

Credential-shaped field names (`api_key`, `token`, `authorization`, and the other names in the classifier) are removed even when the injected denylist is empty. The denylist adds further field names. The removed path is stored in `redacted_fields`. The secret value is not stored. Image byte fields are omitted. `image_ref` / `sha256` are kept. Unknown or non-numeric measurements become null plus a reason. A real zero, such as a pose at the origin, stays zero.

`catalog` stores each JSONL line as its own record. It does not treat the file as one causally valid mission. Goal and unverified landing are both retained.

## Extra edge cases

- A string `"true"` for `simulated` is rejected and is not journaled.
- `epoch` must be a non-negative integer. A boolean is not accepted as `1`.
- An injected field name such as `session_cookie` is removed only when the caller lists it. It is kept when the denylist does not name it.
- `api_key` and `authorization` values are absent from the stored line, and the field paths are listed in `redacted_fields`.
- A future payload key `team_field` is retained beside the core ids. `log_schema` stays `proposed-1`.
- Pose `x_m`/`y_m`/`z_m` of `0` stay `0`. A null RSSI median stays null with reason `unknown`. A non-finite median stays null with reason `not_finite` and is not written as zero. A boolean measurement becomes null with reason `not_a_number`.
- Publish before flush is rejected. The journal double's `published` summary stays unset.
- After a failed flush, publish is refused.
- A catalog line that lacks `command_id` does not erase the earlier accepted line.
- An unknown mission `event` string is stored as `observation` under that string, so it is not renamed to `demo_goal_reached`.
