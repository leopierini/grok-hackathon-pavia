## Behavior

A window can guide only when `receiver_mount` is `dog`, `receiver_id` is the armed Pi, the BSSID matches the armed beacon, `beacon_epoch` equals the hold epoch, the hold is `stable`, every sample pose is on the navigation map epoch, and the Pi heartbeat is healthy and fresh. The reported median and spread are kept when they match the samples. The interface name is stored and not opened.

`quality` `noisy` or `stale` is an observation with `follow` false. No signal is `quality` `unavailable`, empty samples, and null median and spread. `0` with an empty sample list is rejected and is not published as a statistic. A measured `0` dBm that has a pose and a matching median stays `0`, because the closed range includes it.

Epoch mismatch and a moving or unknown hold return `blocked` / `incomparable`. Other refusals return `failed`. Laptop RSSI, including a renamed kind, is rejected. No heading, bearing, or range field is created. No dog command is proposed.

Message kinds accepted: `rssi.window` from `pi`, and `heartbeat` from `pi`.

## Extra edge cases

- A string such as `"3"` or `"true"` is rejected. Booleans are not numbers.
- `clock_error_ms` equal to 50 is accepted. 51 is rejected. The same limit applies to the heartbeat clock.
- Heartbeat age equal to 2000 ms is accepted. One millisecond over is rejected. A missing, unhealthy, or ahead-of-receive heartbeat is rejected.
- A heartbeat from another mission epoch is rejected.
- `quality valid` with an empty sample list is rejected. `unavailable` with samples, or with a non-null statistic, is rejected.
- An empty list with `spread_db` 0 is rejected even when the median is null.
- A reported median or spread that does not match the samples is rejected and is not replaced.
- RSSI below -150 or above 0 is rejected. More than 100 samples is rejected.
- A pose with `valid` false, another `map_id`, a duplicate `sample_id`, or `window_end` before `window_start` drops the window.
- An unknown payload field such as `heading` is rejected.
- A cancelled ticket returns `cancelled` and does not validate the window.
- Replaying the example returns the same median. `state.apply` and the journal stay untouched. Device calls stay empty. No socket is opened.

- Nothing here measures a real Pi, opens `wlan-measurement`, or moves the dog.
