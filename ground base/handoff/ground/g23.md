## Behavior

One approved step becomes one `dog.command` envelope (`protocol_version` `2.0-draft`). Proposal action `approach` becomes `move_local`. The envelope copies `candidate_id`, `snapshot_id`, and `map_epoch` from the single safe candidate, and copies `track_id` and `beacon_epoch` from the selection or proposal. `correlation_id` is the proposal `message_id`. A selection-only step and a halt use `correlation_id` null. Direction hints and the raw proposal body stay out of the command.

`lease_ms` and `duration_ms` are integers from 1 through 500. A longer ordinary step is rejected. Omitted step values default to 300 ms. Halt uses action `halt`, motion null, the same schema, and a default lease of 500 ms. The halt reason says it is a posture-preserving stop and that the dog app must recheck. Halt is issued when standing, avoidance, the candidate, or the tether would block an ordinary step. The request flag `halt_latched: true` refuses ordinary approval before the store is consulted, including when a move for that selection was already stored.

`standing` and `avoidance_enabled` must be exactly `True`. Ethernet refuses a step whose fixture distance is greater than `tether_budget_m`; an equal distance is allowed, and a missing budget fails closed. Wi-Fi ignores those cable numbers. A missing beacon rejects an RSSI step. A visual step is allowed when readiness says `vision_active` is true and guidance is `vision`. Operator up/down/left/right/forward/back are ground-frame requests: up and forward are +x, down and back are −x, left is +y, right is −y. The command has no altitude field. An altitude key on the payload rejects the request, including a halt that also carries one.

The first new move on a feature is `cmd-dog-001` (`msg-cmd-dog-001`). The first new halt is `cmd-dog-halt-001`. The manual clock starts at `2026-01-01T00:00:00Z`, so a 300 ms lease expires at `2026-01-01T00:00:00.300Z`. Replay of the same step or halt identity returns that id, sets `replayed` true, and emits no second event. A different `selection_id` mints `cmd-dog-002`. The dog port is never called. The example command path leaves the journal record list empty.

## Frame convention for the dog teammate

`dog/base_link` only. Positive linear x is forward, positive linear y is left, and positive angular z is counterclockwise when viewed from above. The schema has no linear z. Operator up and down stay in the ground plane. The dog app owns the Unitree body-frame mapping, tests that mapping itself, and rechecks the command before motion. Ground does not import the Unitree client.

## Extra edge cases

- Lease and duration of 500 ms are accepted. 2000, 0, and a boolean lease are refused.
- The string `"true"` for standing or avoidance is refused. Null fails closed.
- An unsafe candidate, a blocked candidate list, an expired `valid_until`, a wrong `target_component`, a bad `frame_id`, and an ambiguous candidate id are refused.
- A selection `snapshot_id` or `map_epoch` that disagrees with the safe candidate is refused. The command copies the candidate values.
- Vision with `vision_active` true allows a null beacon. RSSI without a beacon is refused.
- Stand uses zero velocities. Turn requires an explicit `angular_z_rad_s`. The motion object has no `linear_z_m_s`.
- Candidate expiry is checked before the store. A replay whose candidate is already expired is refused and does not mint a new id. The dedicated expiry test covers the first request.
- Issuing halt stores one halt command. A later ordinary move is refused only when that request sets `halt_latched` true, which matches the fixture latch in the task card.
- Device call lists are compared before and after approval. A change fails the request with `dog port was called`.

## Limitations

- This machine ran CPython 3.12.10. Mypy checks with `python_version = 3.11`. A 3.11 interpreter was not executed.
- Nothing here walks a Go2, measures a cable, or checks a Unitree axis map. Default speeds of 0.1 m/s and 300 ms are the synthetic example profile. They are not derived from `delta_x_m` and they are not hardware settings.
- Gate C must admit schema `ground-task-v2` and slot `feature.v2_dog_command` before `python -m patrol.ground.sim --task 23` can load this manifest. The package leaves the v1 loader unchanged, so the CLI result above stays `schema_mismatch: unsupported schema ground-task-v2` until that admission.
- A halt request that also carries an altitude field is rejected. The altitude key is not stripped.
- The step idempotency key ignores `operator_axis`. Two axes on one feature with the same selection replay the first command. The axis tests use a fresh feature per direction.
- Command ids restart at `cmd-dog-001` and `cmd-dog-halt-001` on each feature instance.
- The provider does not write the journal. Delivery, acknowledgement, and expiry after the dog app receives the JSON belong to later tasks.
