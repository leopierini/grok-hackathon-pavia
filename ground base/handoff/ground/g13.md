## Behavior

The example observation is accepted: flight state `airborne`, height `4.0`, reference `floor_agl`, beacon epoch `3`, pose `null`, battery `74`, downward frame metadata kept, `active_command_id` null. `floor_agl_claim` is true only as a stored label. It is not takeoff permission.

The same `4.0` with reference `unknown` or `takeoff_relative` stays on that reference and `floor_agl_claim` is false. A caller-supplied `height_label` of `floor_agl` is rejected unless the observation reference is already `floor_agl`. `floor_agl` with a null height is rejected. Unknown flight state stays unknown when a frame is attached. Null pose, null battery, and null frame stay null. A reported pose is copied and no axis is invented.

Beacon id, BSSID, SSID, beacon epoch, hold state, `verified_at`, and `hold_valid_until` are required. A BSSID that is not six octets is rejected. Hold state is stored and `beacon_policy` is `deferred`; this task does not decide that the beacon is stable enough for the dog. An active command id is stored with `command_completed` false.

Sender `sent_at` and local `received_utc` / `received_monotonic` are both kept. A mismatched mission epoch, a ticket from an older authority generation, or a latched cancellation produces no event. A second copy of the same message id returns the stored record and no second event. A different payload with that id is rejected. Image bytes are not opened.

## Extra edge cases

- `floor_agl` cannot be applied as a label over `takeoff_relative`.
- Battery values outside 0–100, booleans, and numeric strings are rejected. Null battery is kept. `0` and integral `74.0` are accepted as integers.
- `validated: "true"` and a null acceptance reference do not arm the drone.
- Uppercase BSSID octets are stored in lowercase. Five, seven, and dashed forms are rejected.
- A partial pose is rejected rather than completed.
- A missing hold window is rejected.
- Replay of the same `message_id` is idempotent; a changed payload is not.
- A Windows path in `image_ref` is carried through and not opened.
- Cancellation before ingest stores nothing.
