## Accepted kinds and routes

Every kind in `message.schema.json` is schema-checked. A payload that does not match its kind is `payload_shape`. Source and destination must be the pair below. `capabilities.report` also requires `payload.role` to equal `source`.

| Kind | Source → destination |
| --- | --- |
| `capabilities.report` | dog, drone, pi, or vision → ground |
| `drone.observation` | drone → ground |
| `dog.observation` | dog → ground |
| `rssi.window` | pi → ground |
| `navigation.candidates` | dog → ground |
| `vision.request` | ground → vision |
| `vision.decision` | vision → ground |
| `motion.proposal` | vision → ground |
| `dog.command` | ground → dog |
| `drone.command` | ground → drone |
| `command.ack` | dog or drone → ground |
| `proximity.evidence` | ground → ground |
| `mission.event` | ground → all |
| `heartbeat` | dog, drone, or pi → ground |

`operator` is a legal schema source and is rejected here because none of these kinds use it. A null pose stays null. `evidence_frame_id` is reported as `frame_id` when the payload has no `frame_id`. Several distinct values for one correlation key are returned as a tuple.

`dog.command` / `drone.command` / `motion.proposal` / `vision.request` require a non-null `expires_at`. Ordinary commands, proposals, vision requests, and drone `hover` are rejected when `expires_at` is not strictly after the kernel clock. `dog.command` `halt` and `drone.command` `land` stay schema-valid after that time. This card only parses them.

Shipped example `message_id`s and their `sha256` values are synthetic. `simulated: false` on that id, or on a message that still carries one of those hashes, is `simulated_synthetic`. A new id with a new hash and `simulated: false` is parsed and still does not call an adapter.

## Rejection diagnostics

`error.detail` is one of: `invalid_json`, `utf8_bom`, `trailing_json`, `missing_message`, `not_object`, `unknown_field`, `missing_field`, `invalid_type`, `protocol_version`, `unknown_kind`, `payload_shape`, `expected_direction`, `direction`, `expiry_required`, `expired`, `epoch_mismatch`, `mission_mismatch`, `simulated_synthetic`, `message_immutable`, `command_conflict`, `stale_epoch`.

The matching `GroundError.code` is the frozen allowlist code (`invalid_input`, `schema_mismatch`, `validation_failed`, `rejected`, `expired_deadline`, `epoch_mismatch`, `contract_mismatch`, or `stale_ticket`). Status is `blocked`. Journal and event payloads contain `diagnostic`, and when parsing got that far, `mission_id`, `epoch`, `kind`, and `message_id`. They do not contain the payload, image hash, or reason text.

The same `message_id` and body returns the stored result and does not journal again. The same `message_id` with a different body is `message_immutable`. The same `command_id` and payload returns the stored result even under a new `message_id`. A different payload for that `command_id` is `command_conflict`. A replay does not rewrite `expires_at`. A result that passes the epoch check and then waits across `authority.reset_generation` is `stale_epoch` and is not stored.

## Extra edge cases

- Leading comments, trailing commas, truncated JSON, and duplicate keys are `invalid_json`. A second JSON value is `trailing_json`. A UTF-8 BOM is `utf8_bom`.
- A string `"true"` is not a boolean.
- The caller’s `expected_source` / `expected_destination` must match the envelope, and that pair must match the kind.
- An open snapshot’s `mission_id` must match the envelope. With no open snapshot, the session epoch is `kernel.authority.epoch`.
- After the clock passes `expires_at`, a byte-for-byte replay still returns the original acceptance. A new ordinary command with the old expiry is `expired`.
- A reason containing `sk-live-secret` is absent from the journal record and the proposed event.

## Limitations

- Per-publisher sequence gaps, clock-offset negotiation, and lease refresh across reconnect are not enforced. Duplicate identity does not extend `expires_at`.
- Drone `hover` is treated as an ordinary command. Only dog `halt` and drone `land` skip the expiry clock. Task 28 still has to rank a parsed halt.
- Correlation tuples preserve disagreeing ids. They are not rejected.
- `operator` cannot send any of the fourteen kinds through this gate.
- Nothing here measures a robot, a radio, or a model. The official `patrol.ground.sim --task 11` command stays red until Gate C admits `ground-task-v2`.
